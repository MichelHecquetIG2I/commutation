Méthode de calcul

Le problème est axisymétrique : on résout dans le demi-plan méridien (r, z) l’équation de la magnétostatique pour la fonction de flux ψ = r·Aθ :

−∂/∂r(ν/r·∂ψ/∂r) − ∂/∂z(ν/r·∂ψ/∂z) = J

  • Les lignes de flux sont les courbes ψ = constante ; le flux à travers un disque de rayon r vaut Φ = 2π·ψ.
  • Champ : Br = −(1/r)·∂ψ/∂z, Bz = (1/r)·∂ψ/∂r.
  • Maillage triangulaire (éléments du 1er ordre) aligné sur les matériaux, raffiné autour de la bobine ; domaine de 400 mm avec ψ = 0 à la frontière et sur l’axe ; symétrie z = 0.
  • Flux embrassé : λ = N·⟨Φ⟩, moyenne de 2π·ψ sur la section du bobinage ; inductance L = λ / I (sécante si le fer sature).
  • Fer non linéaire : B(H) = µ0·H + (2·Js/π)·atan(π(µr−1)µ0H / 2Js), Js = 1,7 T ; résolution par Newton-Raphson.
  • Contrôle : en linéaire, l’énergie W = ∫B²/(2µ) dV donne L = 2W/I², qui doit coïncider.

Réseau de réluctances maillé (MEC) — modèle du L2EP (F. Gillon, O. Bouchakour ; thèse de V. Martin, § 4.2.1), transposé en axisymétrique :

  • Grille de n × n cellules (n ≤ 50) alignée sur les matériaux ; un nœud par cellule relié à ses voisins par 4 demi-branches (droite, haut, gauche, bas).
  • Réluctances : radiale R = ln(r₂/r₁) / (2π·µ·Δz), axiale R = (Δz/2) / (µ·π·(r₂² − r₁²)).
  • Inconnues : flux de mailles φm aux coins des cellules (= flux à travers le disque de rayon r) ; flux de branche = différence de deux flux de mailles ; φm = 0 sur l’axe et sur tout le pourtour (Dirichlet).
  • Loi des mailles (Hopkinson) : Σ R·φ = f.m.m. ; les conducteurs sont remplacés par des sources : chaque maille reçoit les ampères-tours qu’elle enlace.
  • Fer non linéaire : chaque demi-branche suit B(H) avec son induction B = φ/S ; Newton-Raphson.
  • Flux totalisé λ = N·⟨φm⟩ sur la section du bobinage ; L = λ/I et L = 2W/I² (W = Σ ∫F dφ).
