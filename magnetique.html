Courbe B(H) du fer

Méthode de calcul

Le problème est axisymétrique : on résout dans le demi-plan méridien (r, z) l’équation de la magnétostatique pour la fonction de flux ψ = r·Aθ :

−∂/∂r(ν/r·∂ψ/∂r) − ∂/∂z(ν/r·∂ψ/∂z) = J

  • Les lignes de flux sont les courbes ψ = constante ; le flux à travers un disque de rayon r vaut Φ = 2π·ψ.
  • Champ : Br = −(1/r)·∂ψ/∂z, Bz = (1/r)·∂ψ/∂r.
  • Maillage triangulaire (éléments du 1er ordre) aligné sur les matériaux, raffiné autour de la bobine ; domaine de 400 mm avec ψ = 0 à la frontière et sur l’axe ; symétrie z = 0.
  • Flux embrassé : λ = N·⟨Φ⟩, moyenne de 2π·ψ sur la section du bobinage ; inductance L = λ / I (sécante si le fer sature).
  • Fer non linéaire : B(H) = µ0·H + (2·Js/π)·atan(π(µr−1)µ0H / 2Js), Js = 1,7 T ; résolution par Newton-Raphson.
  • Contrôle : en linéaire, l’énergie W = ∫B²/(2µ) dV donne L = 2W/I², qui doit coïncider.
